Project Overview

This website demonstrates a production-style speaker recognition model trained on MFCC-derived voice features. The backend performs real PyTorch inference using exported weights and normalization artifacts.

The neural network architecture consists of:

  • An input layer accepting a 4000-dimensional MFCC feature vector
  • Two hidden layers with 128 neurons each
  • ReLU activations and regularized optimization
  • An output layer with 50 classes

The model is trained with validation monitoring, learning-rate scheduling, and early stopping to improve generalization under real-world audio variability.

Methodology & Implementation

Data Preprocessing

The raw audio is transformed into MFCC frame matrices, then flattened into a fixed-length vector so every sample matches the same model input shape. Features are standardized with saved training mean/std values for consistent inference.

Evaluation Strategy: separated train, validation, and held-out test sets

Training Process

Training uses Adam with Cross-Entropy loss, adaptive learning-rate reduction on plateaus, and early stopping. This keeps convergence stable while reducing overfitting as epochs progress.

Inference Decision Layer

Beyond top-1 classification, the system adds confidence-aware logic:

  1. Top-k probabilities: returns the strongest speaker candidates for transparency.
  2. Margin checking: compares top-1 and top-2 confidence to avoid ambiguous matches.
  3. Unknown gating: flags uncertain audio as unknown instead of forcing a false identity.

This decision layer improves trustworthiness by preferring calibrated uncertainty over overconfident misclassification.
